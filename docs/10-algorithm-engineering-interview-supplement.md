### 4.3 手写和计算

算法岗位至少应能完成：

```python
def scaled_dot_product_attention(q, k, v, mask=None):
    scores = q @ k.transpose(-2, -1)
    scores = scores / (q.shape[-1] ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    weights = scores.softmax(dim=-1)
    return weights @ v
```

还应能解释：

- 输入输出 Shape；
- 多头拆分和拼接；
- 参数量；
- 时间和空间复杂度；
- Mask 的广播；
- 数值稳定性。

## 10. 算法岗评分表

| 维度 | 分值 |
|---|---:|
| 基础概念准确 | 20 |
| 数学和原理 | 20 |
| 代码正确与可读 | 20 |
| 复杂度和边界 | 15 |
| 实验与评测 | 15 |
| 工程和业务意识 | 10 |

常见失分：

- 只背结论，无法解释公式；
- 代码没有边界和复杂度；
- 把模型名当成架构原理；
- 只看离线准确率，不做数据和错误分析；
- 无法说明显存、时延和成本；
- 不区分资料旧口径与当前实现。
