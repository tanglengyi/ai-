## 3. 十维评分

每项 0–5 分：

- 0：没有理解或证据。
- 1：知道概念。
- 2：能解释方法。
- 3：有模拟案例或局部实践。
- 4：有真实项目和结果。
- 5：有复杂项目、数据结果和复盘，可应对深挖。

| 维度 | 分数 | 证据 |
|---|---:|---|
| 用户与业务问题 | /5 |  |
| 产品战略与路线图 | /5 |  |
| RAG/Agent/模型理解 | /5 |  |
| 系统、数据与权限设计 | /5 |  |
| 评测与 LLMOps | /5 |  |
| 数据分析与实验 | /5 |  |
| 商业化与单位经济 | /5 |  |
| 交付、验收与客户成功 | /5 |  |
| 跨团队推进与领导力 | /5 |  |
| 目标行业专业知识 | /5 |  |
| **总分** | **/50** |  |

### 判断

- **42–50：** 高匹配，可重点准备公司业务和项目细节。
- **34–41：** 可投递，需要补 2–3 个关键缺口。
- **26–33：** 岗位方向接近，但面试深挖风险高。
- **25 以下：** 更适合作为长期目标，不宜只靠背题突击。

## 6. 最终准备清单

- [ ] 60 秒自我介绍与岗位一致。
- [ ] 三个项目均有 2/5/15 分钟版本。
- [ ] 至少一个项目有真实 Baseline 和结果。

- [ ] 能回答为什么选择 RAG/Agent/规则/工具。

- [ ] 能说明成本、ROI 或商业模式。
