对每项打分 0～2：0=没有，1=部分，2=明确负责。

| 能力积累项 | 分数 |
|---|---:|
| 接触真实客户与原始问题 | |
| 参与业务流程与数据建模 | |
| 参与数据和知识治理 | |
| 负责 Golden Dataset | |
| 负责 AI 质量指标 | |
| 参与模型、检索和方案选型 | |
| 能查看 Trace 并做错误归因 | |
| 接入真实业务系统和工具 | |
| 负责上线后的业务指标 | |
| 有生产化、成本和风险管理 | |

参考判断：

- 16～20：高价值 AI 应用岗位。
- 11～15：有积累，但需确认实际职责。
- 6～10：偏功能配置或项目协调。
- 0～5：技术和业务壁垒有限。

分数只用于辅助判断，最终仍需结合团队、业务和个人目标。
