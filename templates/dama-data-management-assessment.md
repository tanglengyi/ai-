## 19. 上线门槛

### 必须满足

- [ ] 数据权威来源和责任人明确。
- [ ] 生产知识已审批且版本有效。
- [ ] 权限过滤在检索和工具调用前执行。
- [ ] 高风险场景有拒答、规则或人工兜底。
- [ ] 固定评测集已覆盖正常、异常、冲突和越权样本。
- [ ] 能记录答案证据、模型、Prompt、索引和工具版本。
- [ ] 有监控、告警、回滚、备份和问题升级机制。
- [ ] 已明确上线后的知识、数据、模型和指标维护责任。

### 不建议上线的信号

- [ ] 依赖少量演示问题判断效果。
- [ ] 文档版本和适用范围无法区分。
- [ ] 事实数据由模型推断而非业务系统查询。
- [ ] 权限只在前端隐藏或回答生成后过滤。
- [ ] 错误统一归为“模型幻觉”，无法分层归因。
- [ ] 没有人工接管和责任边界。
- [ ] 没有长期维护预算和运营人员。
